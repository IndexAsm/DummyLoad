# Electronic Load
A high-power, water-cooled electronic load designed for testing power supplies, batteries, converters, and other high-power electronics.

## [Board Preview](https://kicanvas.org/?repo=https%3A%2F%2Fgithub.com%2FIndexAsm%2FDummyLoad)
Note: There is a bug in the preview. It displays components from the control board next to power board, even though they are deleted in the project.


## Features
* **2 kW maximum power**
* **60 V maximum input voltage**
* **50 A maximum load current**
* **Water-cooled power stage**
* Constant-current (CC) regulation
* Multiple current ranges for improved resolution
* Designed for continuous high-power operation
* Custom-built control and measurement electronics


## Specifications

| Parameter       |             Specification |
| --------------- | ------------------------: |
| Maximum Power   |                  **2 kW** |
| Maximum Voltage |                  **60 V** |
| Maximum Current |                  **50 A** |
| Cooling         |         **Water cooling** |
| Regulation Mode | **Constant Current (CC)** |

### CC Regulation Ranges

| Current Range | Resolution |
| ------------: | ---------: |
|        0–50 A |     100 mA |
|        0–10 A |      25 mA |
|         0–5 A |      10 mA |

The selectable current ranges provide finer control at lower currents while maintaining the full **50 A** capability when required.

## Functions

* **Constant-current load (CC)**
* Selectable current ranges
* Input voltage measurement
* Load current measurement
* Power measurement
* Water-cooling system
* High-power continuous-load operation



## Applications

This electronic load is intended for testing:

* Linear and switching power supplies
* DC-DC converters
* Battery systems
* USB power supplies
* High-current power sources
* Custom power electronics
